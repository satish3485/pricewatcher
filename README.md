# 🔔 PriceWatcher

Track prices. Watch for changes. Get notified.

PriceWatcher helps you monitor the prices you're interested in
and receive notifications when they change.

## 🌟 Features

- 🛒 Amazon price tracking
- 🛍️ eBay price tracking
- ✈️ Flight price tracking
- 🏨 Hotel price tracking
- 📈 Stock monitoring
- ₿ Crypto monitoring
- 🔔 Price and market alerts
